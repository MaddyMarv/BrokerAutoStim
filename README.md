### [Broker Auto Stim](https://www.nexusmods.com/warhammer40kdarktide/mods/655)
<img width="865" height="563" alt="image" src="https://github.com/user-attachments/assets/2df2d66a-a308-4cfa-9aba-d4395db3ce12" />

Standalone mod that handles using your broker stims for you. It automatically pops the stim once you have been fighting for a few seconds. It has tons of customization. You can set up multiple profiles, cancel the injection animation automatically, and prevent it from firing while you are attacking, blocking, or doing interactions.


**Options:**
- Toggle Auto-Stim (Hotkey)
- Active Profile [Profile 1-5]
- Cycle Profile (Hotkey)
- Show Settings on Profile Switch
- Number of Profiles to Cycle
- Only With Chemical Dependency
- Not with Stimm Supply
- Stim Trigger Mode [Combat Only (use sliders), Non-Combat Only (use sliders), After Ability, Before Ability, Always Stim]
- Combat Duration (seconds)
- Out of Combat Timeout (seconds)
- Animation Cancel Stim
- Cancel Injection Options (on Push/Block, on Reload, During Interactions, During Combat Ability)
- Cancel Injection While Options (Attacking, Carrying Luggable, Using Auspex)
- Attack Cooldown (seconds)
- Block Injection Near and Detection Range Options (Dog, Trapper, Burster, Crusher/Mauler, Rager)
- Show HUD Icon
- HUD Icon Size
- Enable Debug Messages
