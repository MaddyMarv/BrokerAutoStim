### [Broker Auto Stim](https://www.nexusmods.com/warhammer40kdarktide/mods/655)
<img width="865" height="563" alt="image" src="https://github.com/user-attachments/assets/2df2d66a-a308-4cfa-9aba-d4395db3ce12" />

Automatically uses your Broker stim in combat. Supports profile switching, animation cancels, and combat safety checks so it won't interrupt attacks or interactions.

**Options:**

**General Settings**
- Toggle Auto-Stim (Hotkey)
- Show HUD Icon
- HUD Icon Size

**Profile Settings**
- Active Profile [Profile 1, Profile 2, Profile 3, Profile 4, Profile 5]
- Cycle Profile (Hotkey)
- Show Settings on Profile Switch
- Number of Profiles to Cycle
- Only With Chemical Dependency
- Not with Stimm Supply
- Stim Trigger Mode [Combat Only (use sliders), Non-Combat Only (use sliders), After Ability, Before Ability, Always Stim]
- Combat Duration (seconds)
- Out of Combat Timeout (seconds)
- Animation Cancel Stim

**Auto Inject Prevention**
- Cancel on Push / Block
- Cancel on Attack (with Attack Cooldown)
- Cancel While (Carrying Luggable, Reloading, Interacting, Using Auspex, During Combat Ability)

**Dangerous Enemy Detection**
- Block Near Threat & Range Options (Hound, Trapper, Poxburster, Crusher / Mauler, Rager)

**Debug**
- Enable Debug Messages
